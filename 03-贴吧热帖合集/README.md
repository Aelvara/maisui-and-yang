# 03 · 贴吧热帖合集

按原汇总帖顺序整理的 **40 项**故事。这些篇目来自同一批整理工作：以百度贴吧（多为孙笑川吧）的长帖为源，逐楼抓取、校对、排版，做成可打印的 PDF、可编辑的 Word 和纯文本 TXT。

## 文件组织

```text
03-贴吧热帖合集/
└── stories/
    ├── <篇名>.pdf          可打印版，保留配图与楼中楼
    ├── <篇名>.docx         可编辑版
    ├── <篇名>.txt          UTF-8 纯文本，保留 [图片] 位置提示
    └── 无图版/
        └── <篇名>-无图版.pdf   纯文字精简版（仅 4 篇）
```

- 文件以**故事标题原文**命名，与贴吧原帖标题一致，便于检索比对。
- 标题中的 `+`、`？`、`！`、`......`、emoji 等均按原样保留；链接中的特殊字符已做 URL 编码，GitHub 网页端可直接点击。
- 每篇的**原帖链接**见文末表格第二列，可直接跳转（原帖若已删除则失效）。

## 三种格式怎么选

| 格式 | 用它的理由 | 注意 |
| :-- | :-- | :-- |
| PDF | 版式固定，配图在正确位置，适合打印或大屏阅读 | 部分长篇体积较大（如《聊着聊着就A了上去》50 MB） |
| Word | 段落结构完整，可批注、可摘录、可重新排版 | 内嵌图片导致体积偏大 |
| TXT | 体积最小，全文可搜索，适合手机与脚本处理 | 配图位置仅以 `[图片]` 提示，无线索图 |

四篇配了**无图版 PDF** 的篇目，正文相同但去掉了所有配图，页数从 20 多页压缩到 2–8 页，适合"只想看文字"的场合：《痛恨自己的无能》《给大伙讲讲我和初恋的故事》《暗恋两年的高中同学 决定拿下》《刚刚......和高中的英语老师确立关系了》。

## 关于内容

这些帖子大多是第一人称的私人叙事：有人写亡妻，有人写白月光，有人写病房里的四年，也有人写一个只见过几面的 KTV 女孩。它们不是严格意义上的文学，语言粗糙、结构松散，甚至常有错别字，但正因为没被修饰过，读起来才像有人坐在你对面说话。

按主题大致可分几类，方便挑着读：

| 类型 | 代表篇目 |
| :-- | :-- |
| 生死与告别 | 《【经年岁月】3月28日致亡妻，女儿很健康，我一天都未曾忘记你》《在一起六年 抗癌四年的女朋友离开我了》《我的白月光在我身旁逝去》《清明十二年》 |
| 少年与同桌 | 《回忆一下高中时候同桌的轮椅女孩》《19岁的你和18岁的我》《暗恋两年的高中同学 决定拿下》 |
| 遗憾与错过 | 《我永远失去了我的白月光》《请告诉她，我不想她》《二十五岁那年，我捡到了这辈子唯一的温柔，最后又亲手还给了人海》 |
| 长帖 / 长篇 | 《我永远失去了我的白月光》（378 页）、《聊着聊着就A了上去》（325 页）、《清明十二年》（242 页）、《鼠鼠的前半生》（155 页） |
| 轻一些的 | 《兄弟们女生找我借钱 该怎么回 在线等急！》《给8u们讲讲鼠鼠的🤡经历》《收获魅魔小姐，但我却辗转难眠》 |
