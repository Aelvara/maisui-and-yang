## 说明

- **格式**：`.mp4` 容器，**只有音轨、没有视频轨**（实测 stream 仅 `soun`），所以体积完全来自音频本身，播放时不会出现黑屏画面。绝大多数播放器（VLC、PotPlayer、iOS/Android 原生播放器、微信）可直接播放；若播放器只认音频扩展名，改名为 `.m4a` 即可，不影响内容。
- **为什么不做成 mp3**：保持原始文件不变，避免二次转码带来的音质损失与体积膨胀。仓库里不做格式转换，是存档的基本原则。
- **音源出处**：抖音作者「闰土的老爷」的朗读视频。原作者与朗读者的权利均需尊重，此处仅作离线保存，不作传播与商用。

## 衍生听法

如果想要更长的连续播放，可以把两段音频按「主篇 → 暑假篇」的顺序拖进任意播放器的播放列表；两段之间没有重复内容，直接连播即可。
