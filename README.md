## 01 · 麦穗与羊

作者 **羊馍干**（百度贴吧用户），由 **黑背雪** 重新排版整理。

故事以第一人称回忆初中同桌宋穗：一个爱玩《火影忍者》、上课坐不住的男生，和一个安静到被老师形容成"哑巴"的女生，从换座位那天开始，一路写到十七岁戛然而止的结局。全文口语化、几乎不煽情，遗憾感却全压在细节里。

## 02 · 死在十七岁的你

同一部作品在流传中有两个名字：**《麦穗与羊》** 是整理成册后的标题，**《死在十七岁的你》** 是百度贴吧原帖的标题。本仓库两个名字都保留——整理文本放 `01`，原帖形态放这里。

| 文件 | 说明 |
| :-- | :-- |
| `死在十七岁的你-百度贴吧-11154787731-只看楼主-截图.html` | 原帖「只看楼主」全帖截图存档（帖子 tid `11154787731`）。单文件 HTML，图片内嵌，双击即可离线阅读 |
| `来源说明.md` | 上游仓库 `Yukikaze030/YouDiedAtSeventeen` 的原始说明 |

这份 HTML 的价值在于**保留了原帖的可见形态**：楼层的断句、配图位置、发布顺序都在。文字整理版会做润色与合并，截图不会。

### 去重与取舍清单

为了让仓库停留在可克隆的体量（654 MB，而非 1.2 GB），做了以下处理，逐条可核查：

1. **压缩包不再入库。** 本地 5 个 zip 实际只有 2 种内容（MD5 `42b2d58…` 与 `9af8929…`），且解包后与入库文件重复，全部舍弃。
2. **重复的三件套只留一份。** 本地「贴吧故事合集」里的 40 篇 PDF/Word/TXT 与 `viral-posts-archive` 的版本同源，统一采用仓库版（它多出 4 个无图版）。
3. **477 MB 中间产物未收录。** 本地每篇故事下的「原始文件」目录（贴吧逐楼截图 + Markdown 抓取件）属于加工中间态，配图已包含在 PDF/Word 里。仅《麦穗与羊》例外——它的原帖存档作为"母本"保留在 `01-麦穗与羊/04-原帖存档/`。
4. **近乎重复的两版正文合并。** 独立发布版与合集内版本正文逐行比对仅差一行备份链接，只保留独立发布版。
5. **文件名规范化。** 去掉贴吧 tid 后缀，如 `一颗麦穗12.31.3.26.1107125531.pdf` → `一颗麦穗12.31.3.26.pdf`。

## 维护与贡献

欢迎补档、纠错、补图，请遵守以下约定：

1. **新增篇目**放在 `03-贴吧热帖合集/stories/`，同名保留 `.pdf` / `.docx` / `.txt` 三件套。
