# 01 · 麦穗与羊

> 羊羊爱吃穗穗，穗穗爱着羊羊。

## 这是一部什么作品

第一人称回忆体。男主杨沫，爱玩《火影忍者》，上课坐不住，因为课堂捣乱被老师调了座位，新同桌叫宋穗——安静、成绩好、话少，老师甚至带着挑衅说"我就不信这你还能说上话"。故事从换座位那天写起，一路写到十七岁。

全文几乎没有抒情句，靠对话和细节推进：谁给谁带包子、谁在夜里给谁焐脚、谁把伞往谁那边偏。最后留下的东西很轻，也很重。

## 你可能想知道的几件事

- **为什么会有 59 页和 60 页两个 PDF？** 同一份排版稿带封面与不带封面的两次导出，内容相同，都保留是怕日后有人做版本比对。
- **为什么不放压缩包？** 本地原来的 5 个 zip 只有 2 种内容，且解包后与现有文件重复，留着只会让克隆变慢。
- **为什么原稿是图片？** 作者提交的原始文稿以分页图片流传，没有可编辑的源文件，因此只能以图片与合订 PDF 两种形态保存。
