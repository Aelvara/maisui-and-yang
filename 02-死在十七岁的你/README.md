## 名字的关系

同一部作品，两个名字：

- **《死在十七岁的你》** —— 百度贴吧原帖使用的标题（tid `11154787731`）；
- **《麦穗与羊》** —— 故事流传中被叫开的书名，也是整理成册后的标题。

贴吧补档帖从一开始就是把两个名字并列发布的（「【补档】《麦穗与羊》《死在十七岁的你》」），所以这里不做取舍：整理后的文本放 `01-麦穗与羊/`，原帖形态放本目录。

## 这个 HTML 有什么用

整理版会做三件事：合并楼层、修错别字、调整分段。这三件事都让文字更好读，也都让原文的**呼吸感**消失了一点。截图存档保留的是：

- 每层楼的**断句位置**——作者是在哪里换的行、哪里留的白；
- **配图的插入点**——图出现在哪段话之后，而不是集中放在文末；
- **发布顺序与时间戳**——能看出哪些段落是隔了几天才补的；
- **楼中楼的位置**——读者的反应夹在正文中间。

如果你要引用原文、考据版本、或者只是想知道"当初读到的样子"，看这个文件；如果只想顺畅读故事，看 `01-麦穗与羊/01-正文/`。
